# Aplicación Empresarial en Streamlit

Aplicación interactiva, profesional y lista para producción que incluye:

- Facturación
- Punto de equilibrio
- Gestión de stock
- Reportes y exportación a PDF

## Uso

1. Instala las dependencias:

```
pip install -r requirements.txt
```

2. Ejecuta la app:

```
streamlit run main.py
```

¡Modifica los módulos en la carpeta `pages/` para personalizar!
